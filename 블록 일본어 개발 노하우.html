2. 이번에 배운 교훈 → 다음엔 이렇게

📄 기능 고치기 전에 백업 — app_v62.js처럼 버전 폴더 복사 또는 Git 사용. 버전 꼬임의 80%는 롤백 불가에서 온다.
✏️ 수정은 한 번에 한 기능 — 고치고 → 새로고침 확인 → 다음 기능. 동시 수정이 에러의 주원인.
🏗️ HTML 수정 후 구조 검증 — VS Code 확장「HTML tag checker」또는 F12 → Elements 탭에서 열린 태그 경고 확인.
🔧 공통 로직은 함수 하나로 — 문장 조립 규칙을 buildDisplayText(s) 하나로 만들고 여러 곳에서 호출. 규칙 변경 시 1곳만 수정.
🖥️ 콘솔 로그를 습관으로 — "안 된다" → F12 Console 먼저. 에러 메시지의 줄 번호가 정답을 알려준다.

3. 배포 방법 — 10분이면 휴대폰에서도 사용 가능

GitHub Pages (무료, 추천)

1. github.com 가입 → 새 저장소(Repository) 생성
2. 앱 폴더 전체 업로드 (드래그&드롭)
3. Settings → Pages → Branch: main 선택 → Save
4. 1~2분 후 https://아이디.github.io/저장소명/ 접속 완료

Netlify Drop (가장 쉬움)

netlify.com 접속 → 폴더를 드래그&드롭 → 즉시 배포 완료
